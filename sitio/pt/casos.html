Casos do checklist de aterrissagem

Os casos que você salva a partir do checklist de Entender a empresa aparecem aqui. Ficam salvos localmente neste navegador.

Como adicionar um caso

  1. Duplicar uma página do site como modelo (ex.: criar casos/nome-do-caso.html).
  2. Usar a estrutura: Contexto → Problema → O que eu fiz → Evidência/artefato → Resultado → O que eu faria diferente.
  3. Anonimizar clientes e números sensíveis, conservando a complexidade real.
  4. Adicionar o link no menu lateral e marcar ✅ nesta tabela.
