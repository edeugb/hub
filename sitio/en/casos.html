Cases you save from the Understanding the company checklist appear here. They're stored locally in this browser.

How to add a case

  1. Duplicate one of the site's pages as a template (e.g. create casos/case-name.html).
  2. Use the structure: Context → Problem → What I did → Evidence/artifact → Result → What I'd do differently.
  3. Anonymize customers and sensitive numbers, keeping the real complexity.
  4. Add the link in the sidebar and mark ✅ in this table.
