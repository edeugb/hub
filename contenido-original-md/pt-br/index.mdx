## Como eu uso este hub

- **Consultoria / novo emprego** → Módulos 2 e 3 são o checklist de aterrissagem (dia 1 a 90).
- **Refrescar conhecimento** → cada módulo termina com «Prática» e «Artefato»: teoria não vale sem aplicação.
- **Preparar entrevista** → Banco de entrevistas + os casos como material STAR.
